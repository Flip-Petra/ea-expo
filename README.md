# Expo · Estado del arte

Deck animado (Astro + React) para la exposición del estado del arte.

```bash
npm install
npm run dev     # http://localhost:4321
```

Teclas: → / espacio avanzan, ← retrocede, 1–5 saltan a cada pregunta, Esc abre el índice, C copia la cadena en la tarjeta de búsqueda.

Datos en `src/data/`: `searches.json` sale de `TDP/Fuentes/busquedas/estado-del-arte/p*.toml`; `deck.ts` tiene conteos (Tabla 25), matrices (Tablas 35–48) y papers madre (Simulacro).
